# 职遇 · 招聘聚合交互原型

版本 v1.0，2026-10-29。用于评审网站、微信小程序和管理后台的页面与业务流程。不是生产系统，不接入微信、支付、AI 或真实招聘渠道。

## 打开与检查

直接打开 `dist/index.html`，或运行 `node preview-server.cjs`，访问 `http://127.0.0.1:4173`。无第三方依赖，无需构建。推荐通过 HTTP 使用，浏览器会保存本地演示状态。

运行 `node --test tests/model.test.cjs tests/pages.test.cjs`。测试包含 12 个业务规则场景，以及三端共 41 个页面路由的渲染检查。

## 体验路径

1. 网站筛选岗位 → 打开详情 → 演示登录 → 明确消耗 1 次后解锁；再次打开不扣次。
2. 小程序“我的” → 会员权益 → 选择 V1 → 确认条款 → 创建演示订单 → 模拟微信支付。可选取消、失败、确认中、已付款待发放、成功。
3. 已付款但未到账：切到后台“支付订单”，核对记录并补发权益，再回用户端查看。
4. 在已解锁详情提交反馈 → 后台“用户反馈”核实并补偿 → 用户“我的”看到独立补偿额度。
5. 后台“数据源管理”模拟采集 → “内容审核”核对字段 → 发布 → 网站搜索到新样例。
6. 同级续费后，对未来服务段申请售后 → 后台模拟渠道退款成功 → 查看服务期调整。

顶部可切换三端；“页面目录”可直达页面；“演示工具”可改变会员等级、推进日期、耗尽额度、模拟失败和切换购买可用性；“重置”恢复初始样例。

## 规则与范围

- 普通用户每天 1 次，V1/V2/V3 每天 20/100/200 次；搜索、筛选、翻页、收藏免费。
- 按首次成功解锁岗位详情扣次；同岗位跨日及会员到期后可免费回看。
- 购买当天保留已用次数；同级续费连续增加 30 天；重复发放不延长服务。
- 价格待定，30 天会员及 7 天补偿有效期仅为建议方案。
- 数据全部虚构，仅本浏览器持久化；不同设备、域名之间不共享。本原型内三端共用一个演示用户。
- 支付、退款、账号关联、采集和 AI 提取都是明确标记的模拟；不得用于真实交易和个人资料存储。

## 后续开发边界

静态原型用于评审交互，不提供权限隔离；完整样例数据可从前端源码读取。实际的详情权限、并发扣次、支付验签查单、对账、退款金额核算、服务段暂停与失败恢复、跨设备账号绑定、真实采集及去重归并，需要在服务端实现。

本版可演示未来服务段退款成功后的队列调整；申请中的服务段暂停、退款失败后的剩余时长恢复只保留业务说明，尚未模拟计时。当前已开始的服务转人工核算，具体金额规则待定。

订阅推送、消息、公司关注、高级报表属于后续版本。实际业务开发继续沿用简单 Controller / Service / DTO 分层，不引入 DDD。
