## 已确认的核心要求

- 聚合招聘信息，支持行业、经验、地区等条件筛选，后台每日采集并由 AI 辅助整理入库。
- 提供 Web 管理后台与微信小程序；结合此前网站需求，C 端网站暂纳入范围，是否首期同时上线待确认。
- 普通用户每日新查看 1 个岗位详情，V1/V2/V3 分别为 20/100/200 个。
- 按岗位详情计次，同一个岗位可重复查看；跨日及会员到期后免费回看是当前建议边界。
- 付费会员通过小程序内支付开通；实际可用支付产品与接入资质待核验。
- 使用简单业务分层，沿用现有 api/web/common 工程，不引入 DDD。

## 文档状态约定

已确认、建议基线、待定必须分别标记；原型示例不代表真实收款、真实岗位或已接入数据源。价格不虚构，当前 30 天会员与 7 天补偿额度仅为建议方案。

发生冲突时，以用户最新明确要求为准；页面范围以页面清单为入口，会员、额度和售后细则以《会员与售后规则》为准，更新时同步两份文档。
